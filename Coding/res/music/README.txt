Place background music here (same folder as TypingGame.exe after build: assets/music/).

Required filename:

  bgm.mp3           Looped background music while playing (QMediaPlayer)

If you prefer another format supported by your Qt multimedia plugins, change the filename
in services/BgmPlayer.cpp (setMusicDir) accordingly.

Absolute path pattern:
  <applicationDirPath>\assets\music\bgm.mp3

Source repo path (for authoring):
  ClassExamProject/TypingGame/assets/music/
