Place short WAV files here (same folder as TypingGame.exe after build: assets/sounds/).

Required filenames (code expects these exact names):

  hit.wav           Played when a letter successfully removes an apple
  miss.wav          Played when an apple reaches the fail line
  level.wav         Played when a level is completed

Absolute path pattern:
  <applicationDirPath>\assets\sounds\hit.wav

Source repo path (for authoring):
  ClassExamProject/TypingGame/assets/sounds/
